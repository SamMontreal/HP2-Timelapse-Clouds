# HP2 Timelapse Clouds

Regional volumetric clouds for HP2 Recomp 0.14. Version 1.4.2 restores the 1.3.0 daytime skies, retains the three sunset profiles, and brings moving cloud shadows and light through cloud gaps onto the track. Version 1.4.3 gives the thin clouds on Alpine daytime tracks 41–43 clearer sunlit edges and faster deformation within each cloud. Opaque track surfaces use real-time, cloud-occluded sunlight. Version 1.4.4 adds depth-tested near-ground light scattering and extends moving cloud shadows to bridge decks and other opaque scenery. The default launcher uses 4× cloud speed.

《极品飞车：热力追踪 2》PS2 重编译版 0.14 体积云模组。1.4.2 恢复 1.3.0 的非黄昏天空，保留三组黄昏云，新增赛道地面的移动云影和近地光束。1.4.3 调整 41–43 号秋山白天的薄云。云块之间留出空隙，受光边缘更清晰，细碎边缘和云身按不同速度变形。不透明赛道路面采用实时太阳光照。1.4.4 增强近地体积光，桥面和其他可见不透明场景也会随云层透光率变化。默认四倍云速。
