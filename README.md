# HP2 Timelapse Clouds

Regional volumetric clouds for HP2 Recomp 0.14. Version 1.4.2 restores the 1.3.0 daytime skies, retains the three sunset profiles, and brings moving cloud shadows and light through cloud gaps onto the track. The default launcher uses 4× cloud speed.

《极品飞车：热力追踪 2》PS2 重编译版 0.14 体积云模组。1.4.2 恢复 1.3.0 的非黄昏天空，保留三组黄昏云，新增赛道地面的移动云影和近地光束。默认四倍云速。
