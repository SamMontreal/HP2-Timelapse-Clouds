# HP2 Timelapse Clouds

Regional volumetric clouds for version 0.14 of the PS2 recompilation of Need for Speed: Hot Pursuit 2. Sunlit cumulus with cool bases, independently growing and dissipating lobes and a thin high cloud layer on clear daytime tracks. Low sunlight produces amber edges and orange-lit cloud faces on Mediterranean, alpine and tropical sunset tracks. Desert fragments, alpine wisps and parkland overcast follow their original track weather. Sunlight through cloud gaps forms shafts below the cloud base. Ten regional profiles, solar occlusion and 4× time-lapse motion. Includes normal-speed and original-sky launchers.

《极品飞车：热力追踪 2》PS2 重编译版 0.14 体积云模组。晴天赛道加入带冷色云底的积云和高空薄云。地中海、秋季山地和热带黄昏按太阳方位呈现火烧云和金边。沙漠碎云、山地高薄云及林地阴云保留各自的形态。十组地区云层随风变化，云隙下方可见体积光。默认四倍速，提供原速和原版天空入口。
