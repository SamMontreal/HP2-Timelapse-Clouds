# HP2 Timelapse Clouds

Regional volumetric clouds for the PS2 recompilation of Need for Speed: Hot Pursuit 2. Ten regional profiles, solar occlusion and 4× time-lapse motion. Includes normal-speed and original-sky launchers.

《极品飞车：热力追踪 2》PS2 重编译版体积云模组。十组地区云层随风变化，默认四倍速，提供原速和原版天空入口。
